**直连版操作方式。** 将车放在线上，保持静止，等陀螺仪测好零偏、BLE 收到有效心跳后，在车上向上挥手开始标定和巡线。断开连接、心跳超时或收到遥控急停时，固件拉低 D8（nSLEEP），取消当前动作。重连后需要重新向上挥手。急停后，先向任一方向挥手解除锁存，收到新心跳后再向上挥手才会开动。如果标定被打断，小车会围绕原来的车头方向重新扫描。两块板的固件均已通过 Nano 目标编译，带载停车时间和传感器阈值待实测。

## 传感器硬件

套件里的器件：LTE-4206（红外发射管）、LTR-4206（红外光电三极管）、LM393（双比较器）。

**巡线阵列：4 个传感器，按模拟电压读取。** 光电三极管发射极接地，集电极接模拟引脚，并用上拉电阻接到 **3.3 V**（先试 10–47 kΩ，调到地面和胶带的读数差尽量大）。黑胶带反射的红外光少，三极管导通弱，引脚电压**偏高**（`BLACK_IS_HIGH = true`）。模拟读数能给出连续的线位置，PD 转向才平顺。

**LM393 接法：** 比较器输出（开集电极，上拉到 **3.3 V**）接到同样的引脚。程序用 `analogRead()` 读到的是 0 或满量程，标定扫描会自动适配。这时线位置只有 0、±1、±2、±3 cm 几档，仍然能跑通（见"仿真结果"），但转向不够平顺，误报的"疑似弯道"也更多。每路阈值要在传感器正对胶带边缘时调。

**任何信号都不能上拉到 5 V。** Nano 33 BLE 的引脚只能承受 3.3 V。红外发射管可以从 5 V 经各自的限流电阻供电（每个约 20 mA）。

5 cm 宽的胶带居中时，盖住内侧两个（±10 mm），外侧两个（±30 mm）是白的，但离胶带边只有 5 mm。所以"3 个变黑、其中有一个外侧"这个现象，在弯道会出现，车只偏离中线 5–15 mm 时也会出现。为此示例程序打开了 `confirmCornerByLoss`（见状态机一节）。如果外侧传感器离对侧内侧传感器的距离超过一个胶带宽（再加上光斑大小），比如 ±15/±45 mm，就不需要这个选项；但这比 CAD 里的前横梁宽。

**避障对管：** 前横梁上 ±20 mm 处各装一组 LTE/LTR 对管，向外偏 10°，经过 LM393，把阈值调到离锥桶 6–8 cm 时翻转（讲义图 5）。输出低电平表示前方有物体（`OBSTACLE_ACTIVE`）。探测距离要短：在赛道终点，场地边界墙不能触发绕障。

灯光和阳光里的红外会让读数漂移。请在演示的实验室里标定，并给传感器侧面加遮光。

## 算法

### 1. 标定和归一化（`LineSensorArray`）
启动时机器人在线上原地左右各转 40°（陀螺仪控制），让每个传感器都扫过胶带和地面。每个传感器的最小值记为 0（地面），最大值记为 1（胶带）。只要有一个传感器的读数跨度小于 `MIN_CAL_SPAN`，标定就判为失败，因为没离开过地面的传感器没法归一化。方法来自 Pololu QTRSensors 库（`calibrate()` / `readCalibrated()`），这里重新实现。

### 2. 线位置
对超过噪声门限的传感器计算 `position = sum(v_i * y_i) / sum(v_i)`，`y_i` 是传感器的横向位置，单位米，左为正。思路同 QTRSensors 的 `readLineBlack()`，但用米作单位，所以任意间距都适用。所有传感器都看不到黑线时，位置报在最后一次看到线的那一侧、外侧传感器再往外一点。这样控制器会继续朝那边转，导航器也知道该往哪边找。

### 3. PD 转向加按误差降速（`LineFollower`）
`omega = kp * e + kd * de/dt`。微分项先低通滤波，因为数字传感器的位置是一档一档跳的。速度 `v = cruise - (cruise - minSpeed) * min(1, |e| / fullError)`：误差越大车越慢，和 La Voiture 小车的 `base = PB - KS * |error|` 降速是同一个思路。速度指令先经过 `limitTwist()`：轮速会超限时保留转向角速度，先牺牲前进速度。再用 `toWheels()` 按讲义式 (4)/(6) 换算成左右轮速，最后由每个轮子的编码器 PI 环驱动电机。

kp 怎么选：传感器在轮轴前方 L 处、车速为 v 时，横向偏差满足 `e'' + kp*L*e' + kp*v*e = 0`，所以 `wn = sqrt(kp*v)`，`zeta = L*sqrt(kp) / (2*sqrt(v))`。取 L = 0.07575 m（CAD）、v = 0.25 m/s、kp = 90，得 wn = 4.7 rad/s，zeta = 0.72。L 越长阻尼越大，v 越高阻尼越小。

### 4. 赛道状态机（`LineNavigator`）

| 情况 | 判定条件 | 处理 |
| --- | --- | --- |
| 弯道 | 连续 2 次采样有 ≥3 个传感器为黑，且恰好有一个外侧传感器为黑 | 再往前走 `cornerAdvance`（传感器前伸距离 + 半个胶带宽），让轮轴停在拐角上；朝弯道方向原地转，直到线回到传感器中间（至少转 45°，最多 135°）；停 120 ms，继续巡线。走满 10 cm 后才允许触发下一个弯道 |
| 弯道，开启 `confirmCornerByLoss`（CAD 阵列） | 外侧探头连续检测到疑似弯道后直行观察 7 cm。如果另一侧随后持续出现弯道信号，从新信号的位置重新量 7 cm。 | 胶带消失后再前进 50.75 mm，朝确认的一侧原地转弯。胶带继续则恢复巡线，原信号消失后可再次触发。期间持续检测障碍物。 |
| 线偏到一侧丢失 | 连续 4 次采样没有黑，且最后位置超过 `sideTolerance`（介于内侧和外侧传感器之间） | 朝那一侧最多转 120°，再反向扫到 -120°；仍找不到就停车（`lost`） |
| 赛道终点 | 没有黑，且最后位置靠近中间 | 再往前爬 4 cm；仍没有线就停车（`finished`） |
| 锥桶 | 避障传感器连续 3 次触发 | 刹车；背离触发的那一侧原地转 60°；向侧面开出 18 cm；转回与原线平行；直行 32 cm 越过锥桶；向线的方向转回 60°；开到线上，再前进一点让轮轴压线；朝绕行的那一侧转，直到线居中；继续巡线 |
| 开出途中被挡 | 向外开的时候避障传感器触发 | 倒回出发点，换另一侧再试一次；再被挡，或者在越过锥桶时被挡，就停车（`blocked`）等人处理 |

弯道和回线的流程参考了 La Voiture 小车的路口状态机：检测（去抖）→ 停车 → 前进让轮轴到转向点 → 陀螺仪引导原地转 → 稳定 → 走过一段距离后重新允许触发。不同的是，这里原地转的结束条件是"线回到传感器中间"，而不是转满固定角度；陀螺仪只限定转动范围，所以不是正好 90° 的弯也能过。

绕完锥桶后，机器人朝它绕出去的那一侧转回去。这样车头会沿原来的行进方向对准线；即使碰到的是下一段赛道也一样（底部连接段那个锥桶就是这种情况）。

绕障时用的"线的方向"，是巡线过程中经低通滤波的陀螺仪航向。刚过弯时这个值还没稳定，所以改用过弯前的航向 ± `cornerAngle`（90°）。如果赛道的弯不是直角，把 `cornerAngle` 设为 0。

## 实车调试步骤

1. 台架：先把轮子架空。检查电机转向和编码器符号（正向占空比时计数要增加），然后调轮速 PI：给 `targetLeft/Right` 一个阶跃，记录轮速。
2. 传感器：逐个打印传感器在地面和胶带上的原始读数，调上拉电阻，让两者至少相差几百个计数。确认 `BLACK_IS_HIGH`；如果内侧读数比外侧亮，程序会给出警告。
3. 直线，低速（`cruise` = 0.15 m/s）：加大 `kp` 直到开始振荡，再减半；加 `kd` 抑制振荡；最后提高 `cruise`。
4. 弯道：原地转停得过早或过晚时，先调 `cornerAdvance`（轮轴停的位置），再考虑转速。
5. 锥桶：在真锥桶上量出避障传感器的触发距离。`sideOffset` 设为锥桶半径 + 半个车宽 + 2–3 cm，`passLength` 按上面的几何关系算。
6. 每次运行都记录串口输出（`nav: <状态> (<原因>) at (x, y)`）。
