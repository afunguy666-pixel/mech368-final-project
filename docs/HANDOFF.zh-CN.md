# 交接说明：巡线 / 避障 / 仿真（2026-11-26）

给接手的 agent 或组员。按时间顺序说明这一轮做了什么、用户做过哪些决定、现状和待办。代码和注释是英文，用户用中文交流。

## 1. 项目背景

- 课程：MECH 368 期末项目，差速小车。12 月 11 日现场演示（讲义写的是 KAIS 1180，测试赛道在 KAIS 1220）。
- 两块 Arduino Nano 33 BLE Sense Rev2：一块在车上，一块做手持遥控（BLE）。
- 讲义要求：
  - 电池监测和低电量灯
  - BLE 超过 500 ms 收不到有效包就停车并闪灯
  - 遥控器发急停，在车上的 APDS‑9960 做手势恢复
  - 用遥控器的横滚/俯仰角给出 (v, ω)
  - 用红外对管沿 5 cm 黑线巡线、避开锥桶（讲义图 5）
  - 陀螺仪 + 里程计估计位姿
  - 温度建图（讲义图 6 场地：蛇形赛道、3 个锥桶、一个热角、一个冷角）
- 课程讲义和 "Building Robots" 课件 PDF 是用户在对话里上传的，**不在仓库里**。

## 4. 用户做过的决定（按时间）

1. **La‑Voiture**（Elec‑291‑Group/La‑Voiture，STM32）：只借鉴思路，不复制代码（该仓库没有许可证）。借鉴的是路口状态机（检测 → 停 → 前进让轮轴到转向点 → 原地转 → 稳定 → 走一段后重新允许触发）和按误差降速。航点跟踪控制器暂时**没做**。
2. **巡线 4 路，接模拟口 A0–A3**（用户先考虑过 5 路，最后定 4 路）。**避障 2 路，经 LM393 接数字口**。避障不加第三路，也不在车尾加侧向传感器（当时的结论：收益小，引脚也不够）。
3. **电机驱动用 DRV8833**，IN/IN 慢衰减模式：AIN1/AIN2 = D4/D5，BIN1/BIN2 = D6/D7，nSLEEP = D8，nFAULT = A6。
4. 用户上传过一套 RevD 主板设计（74HC4051 模拟开关读传感器、DRV8833 #3297、硬件 ARM 锁存）。用户明确说**"不需要改成这块板子的东西"**，所以 `line_tracker` 没有按 RevD 的引脚改。现在仓库里的 `firmware/revd/` 是另外的人按 RevD 板写的。
5. **车体几何以团队 SolidWorks CAD 为准**（STEP 不在仓库里）：

## 6. 算法要点和关键参数

- **标定**：启动时原地左右各转 40°，记录每个传感器的最小、最大值，归一化到 0–1。
- **线位置**：加权平均。丢线时报告最后一次看到线的那一侧。
- **巡线控制**：PD，误差越大车越慢；`kp = 90`，巡航速度 0.25 m/s。
- **弯道判断**（这套传感器间距下必须这么做）：示例程序设了 `confirmCornerByLoss = true`。看到"3 个黑、含一个外侧"只算疑似弯道，保持航向直行最多 7 cm，线消失才确认是弯道。确认后再前进 53 mm（= 78 − 25），然后原地转到线居中。没消失就判为误报，继续巡线。
  原因：±10/±30 mm 的阵列在车只偏 5–15 mm 时也会出现同样的黑白组合。
- **其他参数**：`sideTolerance` 0.018，`centredTolerance` 0.008。
- **绕障**：背离触发的那一侧转出 60° → 侧移 18 cm → 平行直行 32 cm → 转回 60° → 找到线 → 前进 → 朝绕出去的那一侧原地转回线上。向外开时被挡，就倒回去换另一侧再试一次；再被挡就停车（`blocked`）。

## 8. 待办和风险

1. **巡线传感器高度**：底盘板离地约 35–39 mm，反射式巡线需要 3–8 mm，要用支架往下吊。仿真是 2D 的，看不出这个问题。
2. **万向球**比轮子着地面高 2.5 mm，车会前倾约 2.9°、车头下沉约 4 mm。前横梁处离 Ø150 圆柱只剩约 1 mm 余量。
3. **待实测、目前是占位值**：电机转速（`MOTOR_TOP_SPEED`，现在假设约 0.95 m/s）、死区、编码器每圈脉冲数（假设 300）、传感器在黑白上的电压、避障触发距离（假设 8 cm）、电池电压。
4. **把 `line_tracker` 并进机器人固件**：挂到 MotionSafety 闸门后面，接上 BLE 急停和手势恢复，再在开发板上编译。注意仓库里现在有两套固件（`firmware/robot` 和 `firmware/revd`），用哪套要先问用户。
5. **已知限制**：
   - 终点前如果车本身偏了 5–15 mm，LM393 版本可能把终点当成弯道，转一圈找不到线后停成 `lost`。模拟量版本没出现过。
   - 温度建图的 `MAP x y t` 输出还没加进 `line_tracker`（旧的演示程序 `line_follower` 里有）。
   - 航点跟踪（La‑Voiture 那份清单的第 3 点）没做。
6. **仿真不模拟的东西**：环境红外光、反射率不均、传感器高度、原地转时打滑、比较器迟滞、`firmware/revd`。
